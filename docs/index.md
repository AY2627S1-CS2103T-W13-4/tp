# PingBook

[![CI Status](https://github.com/AY2627S1-CS2103T-W13-4/tp/workflows/Java%20CI/badge.svg)](https://github.com/AY2627S1-CS2103T-W13-4/tp/actions)

![Ui](images/Ui.png)

**PingBook is a desktop app for secretaries and sales representatives to manage their clients and meetings in one
place.** It is optimized for use through a Command Line Interface (CLI), while retaining the benefits of a Graphical
User Interface (GUI).

* To start using PingBook, see the [_Quick Start_ section of the **User Guide**](UserGuide.html#quick-start).
* To contribute to PingBook, see the [**Developer Guide**](DeveloperGuide.html).
